LangSmith Updates

📦 LangSmith Sandboxes now offers a free trial, so you can give your agents as secure, isolated environment to run code, test changes, and complete long-running work safely. Read Sandboxes docs →‍

💬 LangSmith Fleet: Bring agents into Slack with one click. Tag agents in channels, handle follow-ups and HITL approvals in threads, send and receive documents, and more. Read announcement →

🗣️ Voice agent tracing in LangSmith: Capture audio, STT and TTS latency, interruptions, tool calls, and more in one trace for agents built with Pipecat, LiveKit, OpenAI Realtime, and Gemini Live. Learn more →

Open Source

🧠 OpenWiki Brains: A general-purpose memory layer that turns sources like Gmail, Notion, git repos, X, Hacker News, and web search into a local wiki your agents can use and keep updated automatically. Read the blog →

🔎 Deep Agents and Harbor now provide a unified stack for evaluating agents, with isolated sandbox runs, parallel trials, and LangSmith traces that show why each agent succeeds or fails. Learn more →

🧩 RLMs in Deep Agents: Use dynamic subagents to break large-context tasks into programmatic subagent calls, helping agents reduce context rot and orchestrate work over large inputs. Read guide →
